## What the implementation does

The stored name, explicit permission to translate it, and current language/catalog determine the displayed name. `USE_DEFAULT`, `USE_TRANSLATION` and `USE_USERDEFINE` describe outcomes, not a saved enum. Language changes never rewrite `ID.name`. A real rename clears permission; renaming back does not restore it.

Editing starts with the displayed language. Every workspace name starts with an unselected end caret, including personal/unmarked names and unavailable translations. Space appends at the caret. An explicit selection uses Blender’s existing text-field highlight. Esc or unchanged Enter preserves source/permission; a real edit saves the user's literal text.
